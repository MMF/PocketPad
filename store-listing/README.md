# Google Play store listing

Text for the Google Play listing, kept here so changes are reviewed and versioned. The Play
Console is the source of truth once published; copy changes there by hand.

| File | Play Console field | Limit |
|---|---|---|
| `en-US/title.txt` | App name | 30 characters |
| `en-US/short_description.txt` | Short description | 80 characters |
| `en-US/full_description.txt` | Full description | 4000 characters |

The store title is set only in the Play Console. The launcher label in the app
(`app_name`) is just "PocketPad".

Only list features that have been confirmed on real hardware (see "Tested combinations" in the
main README). When a new computer or phone is confirmed, update "Good to know".
